IMPORTANT: If you already have this modpack and are trying to update to the latest version of it, it is strongly recommended that you delete my 'options.txt' file inside the latest 'overrides' folder before importing it into Curseforge.

If you do not, ALL of your current settings will be overwritten! Graphics, audio, keybinds, everything!

And vice versa: If you have not installed this modpack before, it is recommended that you keep my 'options.txt' file so that you avoid having to remap an overwhelming number of keybinds.

Thanks for checking it out!
